# Database asset

The application expects the local SQLite database at:

`assets/smart_medicine_cabinet.db`

The original project contains this database, but it is not included in the public repository yet because its source and redistribution license have not been documented. Before publishing the database, add the data source, version/date, attribution, and license information, then place the file at the path above.

A GitHub-ready copy of the original project was preserved separately during repository preparation.
