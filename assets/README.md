# Database asset

The public repository includes a **small synthetic SQLite database** at:

`assets/smart_medicine_cabinet.db`

It contains only demo records created for development and testing, so a fresh clone can run the local search flow without redistributing the original medicine dataset.

The original project used a much larger database (about 15k Taiwan medicine rows plus a few Japanese rows). That original dataset is intentionally **not** published here until its source, version/date, attribution requirements, and redistribution license are documented.

Do not replace the sample database with third-party medicine data in the public repository unless redistribution is permitted and the README is updated with the required attribution/license information.
